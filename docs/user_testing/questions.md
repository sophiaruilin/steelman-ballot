# Questions (paste into a Google Form, or print)

## 0. Background
1. Participant ID (P1, P2, ...)
2. Phone: iPhone / Android / other
3. Before today, how did you usually decide on ballot measures? (official guide / news / friends or family / endorsements from a party or group / I often skip them / other)
4. How often do you skip ballot measures because you don't know enough? (never / sometimes / often / always)
5. Politically, I generally lean: very liberal / liberal / lean liberal / moderate / lean conservative / conservative / very conservative / prefer not to say *(optional)*
6. Languages you read comfortably: English / Spanish / Chinese / other

## 1. Comprehension (asked after each measure; facilitator marks right or wrong)
**Prop 3 (high-income tax rates)**
- Q1. What does a YES vote do? *(Answer: keeps the existing higher income-tax rates on the highest earners permanently instead of letting them expire after 2030)*
- Q2. About how much money is at stake each year, per the Legislative Analyst? *(Answer: about $5 billion to $15 billion a year)*
- Q3. Name one argument from each side. *(Correct if they give a real supporter argument, e.g. protects school and health-care funding, AND a real opponent argument, e.g. the tax was promised as temporary / spending reform should come first)*

**Prop 39 (voter ID and citizenship checks)**
- Q1. What does a YES vote do? *(Answer: requires government-issued ID to vote, including ID-number digits on mail ballots, plus citizenship checks of voter rolls)*
- Q2. What would change for mail voting? *(Answer: voters list a government ID at registration and write its last four digits on the mail-ballot envelope, instead of signature-only checks)*
- Q3. Name one argument from each side. *(Correct if, e.g., supporters: builds trust / accurate rolls; opponents: eligible voters' ballots could be rejected / cost / privacy)*

Also for each method:
- Time to feel ready to vote: ___ minutes (facilitator records)
- How confident are you about how you'd vote? 1 (not at all) to 5 (very)

## 2. Fairness (on the card they used)
- F1. If you supported **YES**, would you sign the "strongest case for" as your side's best case? 1 = a strawman, 3 = accurate but weak, 5 = "I'd sign it"
- F2. If you supported **NO**, would you sign the "strongest case against" as your side's best case? 1–5
- F3. Overall, does the card lean toward one side? Leans Yes / Balanced / Leans No
- F4. Your own view on this measure *(optional)*: Yes / No / Unsure

## 3. Ease of use (UMUX-Lite; 1 = strongly disagree, 7 = strongly agree)
- U1. This app's capabilities meet my requirements.
- U2. This app is easy to use.

## 4. Sharing

- S3. Did the shared message show both sides fairly? Yes / No / Didn't notice
